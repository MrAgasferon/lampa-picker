# Lampa Picker — «Что посмотреть»

Подборщик фильмов и сериалов на вечер для Lampa / ByLampa. Три вопроса пультом — пять вариантов с причиной выбора. Всё считается на устройстве: без своего сервера, без LLM, без аккаунтов.

Версия: 0.3.0

## Установка

1. Загрузить `picker.js` в репозиторий с включённым GitHub Pages.
2. В Lampa: Настройки → Расширения → Добавить плагин:

```
https://<user>.github.io/<repo>/picker.js
```

3. Перезапустить Lampa. В левом меню появится пункт «Что посмотреть».

## Как работает

1. **Мастер:** время (до 40 мин / 1,5 ч / 2 ч / сериал / неважно) → настроение → компания (один / вдвоём / с детьми / компанией). Повторный запуск предлагает «Как в прошлый раз».
2. **Профиль вкуса** строится из локальных данных Lampa: «Нравится», история, закладки, «Позже», прогресс просмотра. Для 40 самых значимых событий подтягиваются детали TMDB (ключевые слова, режиссёр, актёры).
3. **Кандидаты:** рекомендации TMDB по любимым фильмам + discover по топ-жанрам + закладки «Позже». Предоценка → детали для топ-60 → фильтры → скоринг → MMR (без пяти одинаковых фильмов в выдаче).
4. **Выдача:** отдельный экран. Сверху фон-бэкдроп и описание выбранного фильма: совпадение со вкусом, рейтинги TMDB/КП/IMDb, длительность, жанры, причина выбора, синопсис. Под ним кнопки «Открыть», «Не то» (скрыть на 90 дней), «Уже видел», ниже ряд из 5 постеров, в самом низу «Ещё варианты», «Изменить ответы» и «Журнал».
   - ТВ: фокус на постере сразу показывает описание, OK открывает карточку Lampa.
   - Телефон: постеры листаются свайпом; первый тап выбирает фильм, второй открывает.

5. **Что не предлагается:** «Нравится», досмотренное (≥ 85% или ≤ 10 мин до конца), брошенное, всё, что уже есть в истории Lampa, «Уже видел» и «Не то» за последние 90 дней.

TMDB запрашивается через `Lampa.TMDB.api()`, поэтому плагин автоматически использует прокси, настроенный у пользователя.

**Рейтинги КП и IMDb** загружаются только для видимых карточек: сначала кеш rating.js (`kp_rating`), затем запрос к kinopoiskapiunofficial по imdb_id, запасной вариант — поиск по названию и году. Найденное пишется в кеш rating.js, чтобы тот не запрашивал повторно. Лимит — 120 запросов в сутки на устройство (общий ключ rating.js не выжигаем).

## Журнал подборов

Каждый подбор записывается локально (последние 20 сессий): ответы, профиль вкуса (топ жанров, режиссёров, актёров, seed-фильмы), сколько кандидатов найдено и почему отсеяны, показанные фильмы с разбивкой оценки Q/A/M/N/S и рейтингами, действия («Открыть», «Не то», «Уже видел», «Ещё варианты»).

Экран «Журнал» (с первого шага мастера и снизу выдачи):
- **Скопировать** — в буфер обмена;
- **Поделиться** — системное меню телефона (Telegram и т. п.), если устройство поддерживает;
- **Скачать файл** — `.jsonl`;
- **Очистить**.

Формат: первая строка — метаданные, дальше одна строка JSON на сессию. Из консоли: `LampaPicker.journal()`.

## Проверка на устройстве (первым делом)

Открыть консоль (Lampa в браузере → DevTools) и выполнить:

```js
LampaPicker.diag()
```

Что смотреть в отчёте:

| Поле | Норма | Если нет |
| --- | --- | --- |
| `favorites.like`, `history`, `wath` | Числа > 0 при наличии данных | Другие имена списков в этой сборке — сообщить, поправлю адаптер |
| `timelineSample` | Объект с `percent` | Хеш таймлайна считается иначе — прогресс не учитывается, подбор работает без него |
| `TMDB test` | `OK — <название>` | Проблема с прокси или ключом |
| `kpCache` | Число записей | 0 — rating.js не стоит или кеш пуст, это не ошибка |
| `hasIndexedDB` | `true` | Кеш живёт только до перезапуска |

## Отладка

```js
LampaPicker.debug(true)    // разбивка оценки Q/A/M/N/S под каждой карточкой + логи
LampaPicker.debug(false)
LampaPicker.collect()      // события, из которых строится профиль
LampaPicker.journal()      // журнал в консоль и как строка
LampaPicker.reset()        // сбросить «Не то», «Уже видел» и последние ответы
```

## Ограничения MVP

- Холодный старт без сетки выбора: при истории меньше 5 фильмов подбор идёт по рейтингу и настроению.
- Прогресс сериалов по эпизодам не учитывается — только фильмы.
- Нет раздела настроек: исключение жанров, профиль выдачи, тип контента — в следующей версии.
- Кеш без LRU-вытеснения.
