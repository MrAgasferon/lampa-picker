# Lampa Picker — техническая документация

Версия: 0.13.1 · Описание для пользователей — в [README.md](README.md). Подробная модель подбора с формулами и константами — в отдельном документе «Модель подбора — как работает» (не в репозитории).

## Принципы

- Всё работает на устройстве: нет своего сервера, нет LLM, нет телеметрии.
- Данные берутся из локальных данных Lampa (избранное, история, таймлайн), TMDB и метаданных CUB — тех же, что Lampa показывает в карточке фильма.
- Вкусы конкретного пользователя в код не вшиваются: пороги по годам, доля анимации и жанровые предпочтения считаются из данных.
- Чужие API-лимиты не тратим: ключ Кинопоиска из rating.js не используется.

## Установка

1. Плагин опубликован через GitHub Pages репозитория `mragasferon/lampa-picker`.
2. Lampa → Настройки → Расширения → Добавить плагин → `https://mragasferon.github.io/lampa-picker/picker.js`.
3. Перезапустить Lampa. В меню появятся пункт «Что посмотреть» и раздел настроек с тем же названием.

Версия видна на первом шаге мастера, на экране журнала, в настройках («Версия X.Y.Z») и в консоли: `LampaPicker.version`.

## Конвейер подбора

1. **Мастер:** время (до 40 мин / до 1,5 ч / до 2 ч / сериал на вечер / неважно) → настроение (расслабиться / посмеяться / пощекотать нервы / подумать / удиви меня / неважно) → компания (один / вдвоём / с детьми / компанией).
2. **Сигналы** (`collect`) из `Lampa.Favorite` и `Lampa.Timeline`:

   | Источник | Вес |
   | --- | --- |
   | like | 1 |
   | досмотрено (≥ 85% или ≤ 10 мин до конца) | 0,8 |
   | book, wath, look, scheduled | 0,4 (look — только как сигнал вкуса, в выдачу не попадает) |
   | history, continued | 0,3 |
   | history, начато на 1–20 % больше 14 дней назад | −0,5 (свежее — 0) |
   | thrown | −0,5 |
   | «Открыть» в выдаче | +0,5 |
   | «Не то» без причины или «Не интересно» | −0,2 |
   | «Не то» → «Не мой жанр» | −0,3 |
   | «Не то» → «Не под настроение», «Не для этой компании», «Слишком старое» | 0 (вкус не трогаем) |
   | «Уже видел» | 0 (только исключение) |

3. **Обогащение:** детали TMDB (ключевые слова, режиссёр, актёры) для 25 самых значимых событий.
4. **Профиль:** `n` — события с сигналом, `pos` — положительные (по ним холодный старт — `pos < 5`, поправка настроения по вкусу — `pos ≥ 10`, отсев анимации для пары — `pos ≥ 5`); центрированные веса жанров, доля анимации (`animShare`), порог по годам (`yearFloor` — год, выше которого 90% веса событий; нужно не меньше 10 датированных событий; классика — рейтинг TMDB от 8,0 и старше 25 лет — в расчёт не идёт), seed-фильмы (s > 0,25, до 15; только «Нравится» и просмотренное — список «Просмотрено» или досмотрено; открытое из подборки, закладки и «Позже» влияют на вкус, но опорными не становятся).
5. **Пул кандидатов:**
   - `rec` — рекомендации TMDB по seed-фильмам, подходящим под настроение (до 5 при заданном времени, иначе до 8);
   - `disc` — discover по жанрам настроения;
   - `explore` — жанр с небольшим положительным весом;
   - `kw` — discover по 6 сильнейшим ключевым словам профиля (через «или», вес ≥ 0,3, нужно минимум 2), с фильтрами времени, годов и исключёнными жанрами настроения; причина — «Темы, как в ваших любимых фильмах»;
   - `ppl` — discover фильмов с 3 любимыми режиссёрами и 4 актёрами (`with_people` через «или»), рейтинг от 6,0; причина — «Режиссёр …» / «С …»;
   - `wath` — то, что пользователь сам отложил: «Позже» (`wath`), закладки (`book`), запланированное (`scheduled`). Причина — «Из вашего списка «Позже»» / «Из ваших закладок» / «Из запланированного». «Смотрю» (`look`) сюда не входит.

   Фильм может прийти из нескольких источников: все они хранятся (`srcs`), основной (`src`, для причины и журнала) — по приоритету wath → franchise → rec → ppl → kw → disc → explore.

6. **Префильтр → детали** пачками по 30, лимит 90 карточек (150 в строгих режимах: «до 40 мин» и «с детьми»).
   Не предлагаются: всё из истории Lampa, начатое (фильм — прогресс в таймлайне; сериал — `online_watched_last` или прогресс S1E1–E3, то есть и онлайн-просмотр мимо истории), «Смотрю» (`watching`), «Уже видел», «Не то» за 90 дней, открытое из подборки за последние 3 дня (`opened`), ещё не вышедшее, мало голосов. Фильмы короче 15 минут (`too_short`) не предлагаются ни при каком времени. Эти же правила (`preReason`) применяются к частям франшиз, которые подставляются вместо найденного фильма.
7. **Фильтры** (`postReason`): мало голосов, детский контент вне режима «С детьми» (`kids_content`), анимация для пары или компании при `animShare < 0,2`, возраст в режиме «С детьми» (см. ниже), длительность, отсутствие длительности и т. д. Причины отсева пишутся в журнал.

   Детский контент вне режима «С детьми» (`kidsTargeted`): жанр «Детский» (10762), рейтинги TV-Y / TV-Y7 / TV-Y7-FV или «малыши» (RU ≤ 6+ или US G) среди анимации и семейного. Анимацию для малышей пропускаем, если пользователь любит анимацию (`animShare ≥ 0,3`).
8. **Скоринг:**

   ```
   score = (wq·Q + wa·A' + wn·N + ws·S) / (1 − wm) × (0.15 + 0.85·M) × (0.3 + 0.7·F) × Y × D
   ```

   - Q — байесовский рейтинг TMDB (C = min(среднее по пулу, 6,0), m = 500 для фильмов и 200 для сериалов) плюс поправка по КП и IMDb (см. ниже);
   - A' — совпадение со вкусом, растянутое по текущему списку;
   - S — похожесть на опорные фильмы: число seed-фильмов, в рекомендациях которых встретился кандидат, / 3 (не больше 1); для «Позже», закладок и запланированного — 1;
   - M — соответствие настроению (множитель-«ворота»): 0,3 + 0,7 × лучший положительный вес жанра + сумма отрицательных весов (полностью), затем поправки по компании и шкалам CUB. Положительный вес жанра поправляется на вкус: жанр в профиле ≥ 0,2 — полностью, ≤ 0 — наполовину, между — линейно (при профиле от 10 событий);
   - N — новизна: незнакомый жанр даёт 0,6 только в «Удиви меня», в остальных настроениях 0,15;
   - F — формат (анимация); Y — фактор года;
   - D — нелюбимый жанр: по самому нелюбимому жанру фильма, плавно от ×1 при весе −0,45 до ×0,6 при −0,9 и ниже (кроме «Позже» и режима «С детьми»).

   После скоринга каждый фильм получает сдвиг ×0,92…1,08 от генератора, засеянного датой и ключом фильма: в течение дня у фильма тот же множитель. Показанное сегодня без «Открыть», «Не то» и «Уже видел» при новом подборе получает ×0,85 за каждый показ, не ниже ×0,6 (`picker_shown_day`: ключ → число показов, сбрасывается с новым днём) — пятёрка обновляется частично, а сильный фильм может вернуться наверх.

   Теневая формула (только журнал, `shadow`): вес вкуса +0,10 за счёт рейтинга, совпадение растягивается по процентилям. В журнале — её пятёрка и сколько из неё совпало с показанной (`same`); для холодного старта и «С детьми» не считается.

   Наборы весов (`pickWeights`): «С детьми» — q 0,40, a 0,15, m 0,35, n 0,05, s 0,05 (выбирается первым); «Подумать», «Удиви меня», компания, холодный старт и общий — свои наборы.

   Веса «Подумать»: фантастика, детектив, история 0,8; документальный 0,6; военный, драма 0,5; криминал 0,4; мелодрама −0,2; анимация, музыка, приключения −0,3; комедия, боевик −0,5; ужасы, семейный −0,8.

   Явные причины отказов корректируют профиль только при повторе:
   - «Не мой жанр»: отказ приписывается жанру фильма с наименьшим весом в профиле (драме — только если она единственный жанр). Счётчики хранятся в `picker_genre_rej` (до 300 записей). Жанр, который встретился в 2+ таких отказах, получает −0,3 за каждый отказ сверх первого;
   - «Слишком старое»: после 2+ отказов порог по годам — десятилетие после второго по свежести отвергнутого года (если он выше порога из истории).

9. **Франшизы:** одна франшиза — одна карточка, первая непросмотренная часть (просмотренными считаются досмотренное, история и «Уже видел»). Подставленная часть проходит те же проверки, что и найденный фильм. Если она не прошла (длиннее выбранного времени, начата, мало голосов) — франшиза в этом подборе пропускается, поздняя часть не показывается. Исключение — «С детьми»: если начало серии не подошло по возрасту или содержанию (`kids_*`), остаётся лучшая проверенная часть. Отклонённая часть, «Смотрю» или открытая из подборки за 3 дня — франшиза пропускается целиком. Решения пишутся в журнал (`franchises`: `next_in_list`, `added`, `skip:<причина>`, `fallback:<причина>`, `all_watched`, `blocked:<причина>`, `no_parts` — состав коллекции неизвестен, остаётся лучшая найденная часть).
10. **Разнообразие:** MMR с λ = 0,7, в выдаче 5 карточек.

## Шкалы содержания (CUB)

Источник тот же, что у блока «Метаданные» и тегов настроения в карточке фильма Lampa:

```
{Lampa.Utils.protocol()}{Lampa.Manifest.cub_domain}/api/ai/video-view/{tmdb_id}/metadata?type=movie
```

- Ответ: `status` (`completed` / `empty`), `review: [{name, values[], avg}]` (avg 0–10: humor, violence, fear, tension, romance, sadness, pace, importance, action, sex, profanity), `moods: [{name, percent}]`.
- Только фильмы: для сериалов Lampa этот запрос не делает, и плагин тоже.
- Запрашивается после фильтров, для 20 лучших по предварительной оценке фильмов. Подбор ждёт не дольше 5 с (одновременно с КП), остальное берётся по жанрам.
- Отдельная очередь: 2 параллельных запроса, таймаут 5 с, без повторов, чтобы не занимать слоты TMDB и КП.
- Кеш: `completed` — 30 дней, `empty` — 7 дней; прочие статусы и ошибки сети не кешируются. Встреченные статусы — в экспорте журнала (`cubMeta.statuses`).
- Если у фильма нет главных для настроения шкал (для «Расслабиться» — страха и насилия, «Посмеяться» — юмора, «Нервы» — хотя бы одной из страха, напряжения, насилия, «Подумать» — экшена и юмора), оценка настроения идёт по жанрам: отсутствующая шкала не считается нулём.
- Выключается вместе с метаданными Lampa (`lampa_settings.disable_features.metadata`).

Как используются шкалы:
- 65% оценки настроения M (35% — веса жанров);
- `harshAdult`: насилие или страх ≥ 5;
- для режима «С детьми» повторная проверка после загрузки шкал: страх > 6, насилие > 5, лексика > 3 или откровенность > 2 — отсев (`kids_moods`);
- в описании фильма — четыре самые выраженные шкалы.

## Экран «Настроить вкус»

Сетка известных фильмов и сериалов для быстрой отметки «Нравится».

- Открывается кнопкой «Настроить вкус» на первом шаге мастера; сам — один раз, если в «Нравится», истории, закладках, «Позже» и «Просмотрено» вместе меньше 5 карточек (`picker_taste_offered`).
- Кандидаты: `movie/top_rated`, `tv/top_rated`, `movie/popular`, `tv/popular` (по странице каждого, вперемешку), от 1500 голосов, с постером, без дублей. По 24 за раз, «Ещё фильмы» — следующая порция; страницы 1–5 по порядку, после пятой кнопка пропадает («Больше нет»).
- OK/тап ставит или снимает отметку: `Lampa.Favorite.add('like', card)` / `remove`. Уже отмеченное в «Нравится» показывается отмеченным (`Lampa.Favorite.check`).
- Логику подбора экран не меняет: плагин и так читает «Нравится» (+1,0) при каждом подборе.
- Пачка «Нравится» за один день (от 6 отметок — с этого экрана или вручную) при истории от 30 других событий сглаживается (кроме дня первого запуска плагина, `seen_init`): такие события получают медианную дату истории (меньше «свежести»), вес 0,6 вместо 1,0 и занимают не больше 40% опорных фильмов (6 из 15). В журнале — `profile.likeBatch`.

## Причины «Не то»

После «Не то» открывается меню Lampa «Почему не то?»: не под настроение / не мой жанр / слишком старое / не для этой компании / не интересно / пропустить. «Назад» отменяет отказ. Любой выбор скрывает фильм на 90 дней. Причина хранится вместе с отказом (`fb.rejected[k].r`, а также настроение и компания в момент отказа) и пишется в журнал (`why`). В профиле журнала видно, что сработало: `rejGenres`, `yearFloorBy: 'rejects'`.

## Возрастные рейтинги

Для показа (`cert` на карточке) — как в Lampa: российский рейтинг, если есть, иначе американский. Для фильтров — единая шкала возраста `ageOf`: самый строгий из RU и US (`US_AGE`: G / TV-Y / TV-G — 0, TV-Y7 — 7, PG — 8, TV-PG — 10, PG-13 — 12, TV-14 — 14, R / TV-MA — 17, NC-17 — 18).

`harshAdult` = R + жёсткий жанр (боевик, триллер, криминал, ужасы, военный) или шкалы насилия/страха ≥ 5. Такой контент штрафуется (M −0,25) в настроениях «Расслабиться» и «Посмеяться» и слегка (M −0,1) в режиме «Вдвоём», кроме «Пощекотать нервы» и «Подумать».

## Режим «С детьми»

- Возраст — максимум из `ageOf` и возраста с Кинопоиска (`ratingAgeLimits`). Предел — 12+ (`KIDS_MAX_AGE`). Нет ни одного рейтинга — отсев (`kids_cert`), КП выше 12+ — `kids_kp_age`.
- Возраст с КП запрашивается для 20 лучших после скоринга (`attachKidsAge`, не дольше 5 с, тот же бюджет запросов КП).
- Нет подтверждения (КП не ответил, российского рейтинга нет) — пропускается только то, что по американскому рейтингу не старше 8 (G/PG), иначе `kids_unconfirmed`. Решается на финальной проверке, после запроса к КП.
- Ужасы и военное — отсев (`kids_genre`); шкалы CUB — повторная проверка (`kids_moods`, см. выше).
- Вкус взрослого не мешает: множитель D и поправка настроения по вкусу не применяются, формат F = 1. Настроение: +0,3 за семейный, анимацию, приключения, фэнтези; −0,3 за каждый из триллера, криминала, детектива, военного, ужасов (не больше −0,6). Discover сначала по семейным жанрам.

## КП и IMDb в оценке качества

Поправка к TMDB, а не замена: учитывается, насколько фильм на КП/IMDb лучше или хуже обычного при таком рейтинге TMDB.

```
d_kp   = КП − TMDB − смещение_КП
d_imdb = IMDb − TMDB − смещение_IMDb
corr   = ⅔·d_kp + ⅓·d_imdb   (одна оценка — берётся она; ни одной — 0), ограничено ±2,5
alpha  = 0,15 + 0,15 · m/(голоса + m)      (мало голосов на TMDB — больше доверия КП/IMDb)
       + 0,3 · свежесть · min(1, max(0, |corr| − 0,5))
         свежесть = (3000 − голоса)/3000 при голосах < 3000, иначе 0 — новинки на TMDB завышены первыми голосами
Q      = (взвешенный TMDB + alpha·corr − 5,5) / 3
```

- Смещения шкал считаются по собственному кешу (`kpmap` хранит и TMDB), сжаты к значениям по умолчанию: КП −0,2, IMDb +0,1, с весом 20 наблюдений.
- Оценки берутся из кеша для всех кандидатов, а для 20 лучших после ранжирования без оценки — запросом. Затем список переранжируется.
- Запросы идут от лучшего к худшему, по 3 фильма одновременно. Бюджет на один подбор: 12 запросов со встроенным ключом, 40 с личным. Оценки КП и шкалы CUB запрашиваются одновременно, подбор ждёт их не дольше 5 с.
- Со встроенным ключом плашки на карточках за пределами финалистов («Ещё варианты», дальние страницы) берутся только из кеша.
- Если КП заметно поднял фильм (поправка ≥ 0,15 пункта, КП ≥ 7,5), а более сильного объяснения нет, причина выбора — «Высоко на Кинопоиске: 8,4».
- В журнале по карточке: `kp`, `imdb`, `rsrc` (cache/net), `rc` (поправка в пунктах), `rb` (вклад в рейтинг), `kpMiss` — почему оценки нет (`not_found`, `no_rating`, `cached_miss`, `deadline`, `run_budget`, `daily_limit`, `blocked`, `paused`, `offline`, `no_key`, `net`, `http_NNN`, `not_requested`), `kpProbe` — что ответил КП: когда фильм не нашёлся — поиск по IMDb-номеру, запрос по названию, до 5 вариантов (тип, год, название); когда нашёлся без оценки — какой фильм сопоставлен (id, тип, год, название, голоса); по подбору — `kp: {req, off, rated}`.
- `kpmap`: отметка `r` — оценку спрашивали. Запись без оценок и без `r`, но с id КП (возраст из «С детьми» или старая версия) — оценку запрашиваем по id. «Не найден» из старых версий без записи ответа КП или от прежней версии сопоставления (`mv`) переспрашивается один раз.
- Причина «Высокий рейтинг» — только при рейтинге TMDB от 7,0, если КП не ниже 7,0 и голосов на TMDB от 1000 (или КП подтверждает от 7,0). TMDB 8,8 при КП 6,5 — не «высокий»; тогда «Высоко на Кинопоиске» от 7,5, жанр под настроение или «Ваш жанр». Голоса склоняются: «1 голос», «322 голоса».
- «Что-то новое» называет жанр не из недавних и без заметного отношения в профиле (вес меньше 0,1 по модулю): нелюбимый жанр «новым» не бывает.

## Рейтинги КП и IMDb на карточках

Для показанных карточек, которых не было среди финалистов:

1. кеш rating.js `kp_rating` (если стоит; только для фильмов — ключ без типа);
2. собственный кеш `kpmap` (14 дней);
3. kinopoiskapiunofficial по imdb_id (если в ответе фильм без оценок — оценка берётся из карточки КП по id), запасной вариант — поиск по названию: тип должен совпасть (фильм / сериал), название — тоже (оригинальное или русское); из совпавших берётся ближайший по году в пределах ±3 лет. Год на КП бывает годом производства, на TMDB — годом проката («Связь»: 2012 и 2014). Если название не совпало ни у одного варианта (другой перевод), фильм берётся, только когда вариант того же года один: поиск по слову отдаёт и чужие фильмы («Multiverse» → Entangled 2019 вместо «Мультивселенной» 2018). Записи «нашёлся без оценки» от прежних версий сопоставления (`mv` < 3) переспрашиваются заново один раз.

Найденное пишется и в `kp_rating`, чтобы rating.js не запрашивал повторно.

| Ключ | Лимит на устройство в сутки |
| --- | --- |
| Встроенный (обфусцирован в коде) | 40 запросов |
| Личный (Настройки → «Что посмотреть» → «Ключ Кинопоиска») | 500 запросов (лимит бесплатного тарифа) |

Отдельная очередь (3 запроса одновременно, таймаут 4,5 с, без повторов) не мешает TMDB. Два сетевых сбоя подряд — час только кеш (`diag().kp.offlineUntil`). Квота списывается в момент отправки. Счётчик привязан к ключу и сбрасывается ежедневно. Личный ключ при вводе проверяется пробным запросом. При 402 ключ блокируется до конца суток, на встроенном ключе — без уведомления. На 429 — пауза 60 с (в памяти). Запросы одного подбора привязаны к его контексту: при отмене подбора они снимаются с очереди. Если встроенный ключ исчерпан, раз в сутки в выдаче появляется подсказка про личный ключ.

## Сеть и нагрузка на API

- TMDB вызывается через `Lampa.TMDB.api()`, поэтому используется прокси, настроенный у пользователя: свой, CUB или плагин, подменяющий эту функцию (ByLampa и др.). Если в сборке нет `Lampa.TMDB.api`, адрес строится по логике самой Lampa: свой прокси (`proxy_tmdb` + `tmdb_proxy_api`) → прокси CUB (`apitmdb.<cub_domain>`) → `api.themoviedb.org`. Постеры — через `Lampa.TMDB.image()`; путь постера проверяется (`/имя.jpg`), адрес экранируется.
- Язык данных TMDB — `tmdb_lang` из настроек Lampa (иначе язык интерфейса), входит в ключ кеша.
- Очередь: не больше 4 параллельных запросов. На 429 вся очередь встаёт на паузу 2 с × 2^n, n = 1…3 (первая пауза 4 с, не больше 30 с). Ошибки 4xx не повторяются, сеть и 5xx — один повтор через 1,5 с. Запрос без ответа за 17 с считается сетевой ошибкой.
- Сторож подбора: ошибка, если 20 с нет ни одного ответа TMDB и ни одного нового этапа (`RUN_SILENCE`) или подбор идёт дольше 90 с (`RUN_HARD_LIMIT`). Детали после 25 с от старта больше не догружаются, если прошедших фильтры уже не меньше 10 (`detailsCut` в журнале). Если сработал сторож или детали не загрузились из-за сети, показывается экран ошибки: «Нет связи с TMDB» (были только сбои сети) или «Не получилось подобрать», с кнопками «Повторить» и «Изменить ответы».
- Время жизни кеша: списки (рекомендации, discover) — 7 дней, детали — 30 дней (компактная запись `det2:<язык>:<тип>:<id>`). В памяти — не больше 400 записей (LRU). Раз в сутки при прогреве из IndexedDB удаляются записи старше 35 дней и старые полные ответы деталей.
- IndexedDB открывается не дольше 3 с, иначе кеш работает только в памяти. Чтение — не дольше 8 с: если база не ответила, до перезапуска она не читается, а журнал и `kpmap` не пишутся на диск (кроме явной очистки), чтобы не затереть сохранённое.
- Прогрев: раз в сутки, через 30–120 с после старта, только при наличии IndexedDB. Подтягивает рекомендации по 8 seed-фильмам.

## Хранилище

| Что | Где |
| --- | --- |
| Кеш TMDB/КП/CUB | IndexedDB `lampa_picker`, store `kv`, записи `{t, v}` с TTL |
| Журнал, kpmap | IndexedDB (слой Durable, запись с задержкой 2 с, сброс на `pagehide`/`visibilitychange`) |
| Ответы, «Не то», «Уже видел», квота КП, ключ | `localStorage` с префиксом `picker_` (маленькие объекты) |
| Даты знакомства с карточками | `picker_seen`; момент первого запуска — `picker_seen_init` (импорт на старте не считается «пачкой» лайков). Даты карточек, пропавших из списков, вычищаются, когда их больше 200, а в списках не меньше 20 карточек |
| Счётчики «Не мой жанр» по жанрам | `picker_genre_rej` |
| Показанное сегодня | `picker_shown_day` |

Старые `picker_journal` и `picker_kpmap` при первом запуске переносятся из `localStorage` в IndexedDB и удаляются. Лимит Lampa в 5 МБ не затрагивается.

## Журнал подборов

Локально хранятся последние 20 сессий: ответы, профиль (`events`, `positive`), покрытие шкалами CUB (`cub: [получено, запрошено]`), статистика пула и отсева, показанные карточки с разбивкой Q/A/M/N/S, жанровым множителем `d`, штрафом за повтор `rp` и рейтингами, действия пользователя, теневая пятёрка (`shadow`), решения по франшизам (`franchises`), число карточек со штрафом за повтор (`repeats`). В заголовке выгрузки — статусы ответов CUB (`cubMeta.statuses`). Наружу журнал уходит только при ручном экспорте.

Для чтения журнала на компьютере есть отдельная страница «Разбор журнала подборщика» (не в репозитории): принимает `.jsonl`, `LPJ1:`, `LPJ2:` и «Последний подбор текстом», показывает находки и подборы, считает всё в браузере.

Экран «Журнал» (с первого шага мастера и снизу выдачи):

- **Скопировать журнал** — формат `LPJ2`: gzip + base64, последние сессии, сколько поместится в 3900 символов (одно сообщение мессенджера). У показанных карточек без оценки КП — поле `km`: причина и коротко, что ответил КП;
- **Последний подбор текстом** — читаемый вариант одной сессии;
- **Отправить автору** — весь журнал (`LPJ1`, gzip + base64) и необязательный комментарий уходят POST-запросом на Google Apps Script. Кнопка есть, только если в коде задан `FEEDBACK_URL`. Лимит — 5 отправок в сутки с устройства. Комментарий вводится клавиатурой Lampa: пустой ввод — отправка без комментария, «Назад» — отмена. Настройка приёмника — в FEEDBACK.md, код — `feedback.gs` (оба отдельно, не в репозитории);
- **Поделиться** — системное меню, если устройство его поддерживает;
- **Очистить**.

Наружу журнал уходит только по кнопке: «Скопировать», «Поделиться» или «Отправить автору». Журнал на подбор не влияет. На подбор влияют сигналы «Открыть», «Не то» и «Уже видел», а они хранятся отдельно.

## Диагностика

```js
LampaPicker.diag()
```

| Поле | Норма | Если нет |
| --- | --- | --- |
| `version` | текущая версия | закешировалась старая — перезагрузить Lampa |
| `favorites.*` | числа > 0 при наличии данных | другие имена списков в сборке |
| `timelineSample` | объект с `percent` | прогресс не учитывается, подбор работает без него |
| `TMDB test` | `OK — <название>` | проблема с прокси или ключом TMDB |
| `kp` | `builtin`/`personal`, `today`, `blocked: false` | ключ упёрся в лимит или не прошёл проверку |
| `CUB metadata` | `OK` и шкалы «Матрицы» | CUB недоступен или выключен в сборке — работает оценка по жанрам |
| `idbOpened` | `true` | кеш живёт только до перезапуска |
| `localStorage` | отчёт по занятому объёму | — |

## Консоль

```js
LampaPicker.version         // версия
LampaPicker.debug(true)     // разбивка оценки под карточками + логи
LampaPicker.collect()       // события профиля
LampaPicker.journalFit()    // то, что копирует кнопка (LPJ2)
LampaPicker.journalLast()   // последний подбор текстом
LampaPicker.journal()       // весь журнал
LampaPicker.setKpKey('…')   // личный ключ КП ('' — удалить)
LampaPicker.reset()         // сбросить «Не то», «Уже видел» и последние ответы (даты знакомства не трогает)
```

## Ограничения

- Холодный старт: при истории меньше 5 фильмов подбор идёт по рейтингу и настроению, пока пользователь не отметит фильмы на экране «Настроить вкус».
- Прогресс сериалов учитывается только для исключения начатого (S1E1–E3 и `online_watched_last`), во вкус не идёт.
- Шкалы содержания есть только для фильмов и не для всех; сериалы оцениваются по жанрам.
- Нет настроек исключения жанров и выбора типа контента.
